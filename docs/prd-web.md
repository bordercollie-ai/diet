# Web/PWA 方案 PRD

此文档定义当前唯一实现路线；通用产品范围见 `docs/prd.md`。

## 平台与约束

- 支持现代 Safari、Chromium 桌面浏览器及 iPhone/iPad；可安装为 PWA。
- 使用 IndexedDB 存储，使用下载和文件选择器备份；不需要 App Store、证书、账号、服务器或网络。
- 浏览器能力（安装、通知、后台）因平台而异，且不得阻塞核心记录。
- 不支持 HealthKit 或其他原生健康数据读写。

## 功能要求

- 按日期和时间记录、编辑、删除饮食并汇总每日营养。
- 搜索精选日本食品；创建、编辑、删除用户食品；一次性热量记录不进入食品库。
- 根据个人资料、目标体重和日期计算目标，并支持手动覆盖。
- 导出版本化 JSON；导入必须先校验和预览，按 ID 合并，失败不写入。
- 中英文界面；食品名称可包含中文、日文、英文；支持离线启动。

## 质量与验收

- 领域计算和备份校验必须可通过确定性测试独立运行。
- 不上传饮食、体重或健康数据；存储和导入错误必须明确显示。
- 核心流程支持动态字体、键盘、语义标签和基础屏幕阅读器。
- 在 Safari 和一个 Chromium 浏览器中，离线核心记录、目标、备份恢复和 PWA 启动均可用。

## 不做

账号、云同步、服务器、AI、条码扫描、远程食品 API、HealthKit，以及复杂的跨浏览器通知兼容层。
