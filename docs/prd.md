# 饮食记录 App：MVP PRD

## 目标

提供离线、由用户掌控的饮食记录工具：快速记录饮食和热量、查看每日营养汇总、设定目标、使用日本常见食品或自定义食品，并通过 JSON 备份迁移数据。

## 平台与边界

- 唯一实现路线是 Web/PWA；技术取舍见 ADR 0002。
- 支持现代 Safari、Chromium 桌面浏览器、iPhone/iPad 浏览器和 PWA 安装；界面支持中文、英文、日文。
- 使用 IndexedDB 存储，使用下载和文件选择器备份；数据仅存于设备，无账号、服务器、云同步或运行时网络请求。
- 统计和目标仅供个人参考，不构成医疗建议。

## MVP 功能

1. **饮食记录：** 按日期和时间创建、编辑、删除记录；从食品库选择食品和份量，或直接记录一次性热量；可按日期输入额外运动消耗；显示每日热量、蛋白质、脂肪、碳水及其与目标的差异。
2. **食品库：** 提供精选日本食品（含便利店、连锁店和麦当劳代表项），支持搜索和用户自定义食品。内置数据记录版本与来源；食品库不是完整品牌菜单。自定义食品可通过二维码或可粘贴的文本代码分享给其他设备/家庭成员并导入为新的自定义食品；分享内容仅为食品名称、份量与营养数据，不含 ID 或来源信息，完全在设备本地生成/解析，不经过任何服务器。
3. **目标：** 根据年龄、性别、身高、体重、活动量、目标体重和日期估算目标；用户可逐项手动覆盖。每日热量不超过目标加当天额外运动消耗（≤100%）即为达标；保存的新目标从当天起生效，不重写过去日期的目标范围或状态。
4. **备份：** 导出版本化 JSON，并在校验、预览后合并导入；同 ID 以导入数据覆盖，错误或不支持的文件不改变现有数据。
5. **浏览器能力：** 在支持时提供安装和提醒；不可用时不影响记录。体重、运动和营养均手动输入，不接入 HealthKit。
6. **成就：** 首发提供 22 枚永久成就，围绕资料与目标、记录次数、临时记录、记录天数、达标连续天数、同种食品次数、食品种类和自定义食品建立。每日热量不超过目标（≤100%）时记为达标；奖杯页面首先展示奖章列表，点开可查看取得时间；已读成就不重复弹出或播放庆祝。成就只鼓励按目标记录，不奖励过度限制饮食；徽章用简单的皇冠/星星和数字图形呈现。

## 关键流程

- 首次使用：选择语言，可选填写资料并确认目标，进入今日记录。
- 记录饮食：搜索或创建食品，填写份量和时间，保存后立即更新汇总。
- 备份恢复：选择导出或导入，导入前查看版本和概要，得到明确结果。

## 验收标准

- 离线时可创建、编辑、删除记录，并正确计算每日营养汇总；PWA 可离线启动。
- 可搜索内置日本食品并创建自定义食品。
- 自定义食品可生成二维码与文本代码分享，并可通过相机扫描（在支持的浏览器上）或粘贴文本代码导入为新的自定义食品；无效或损坏的代码不改变已有数据。
- 自动目标和手动覆盖均正确。
- 导出数据可恢复；损坏或不支持的备份不修改已有数据。
- 在 Safari 和至少一个 Chromium 浏览器完成核心流程与 PWA 验证。
- 核心流程支持键盘、基础屏幕阅读器、动态字体和浅色/深色模式。
- 领域计算和备份校验可通过确定性测试独立运行；存储和导入错误明确显示。

## 不做

AI 识别、条码扫描（扫描超市商品条码并联网查询商品数据库）、账号、服务器、云同步、社交、远程食品 API、完整品牌菜单、复杂食谱、过敏原筛选和医疗建议。（自定义食品的二维码/文本分享导入不在此列：不查询任何商品数据库，不发起网络请求，仅在设备间转移用户自己输入的营养数据。）
