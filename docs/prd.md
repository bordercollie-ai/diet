# 饮食记录 App：MVP PRD

## 1. 产品目标

提供一个离线可用、数据由用户掌控的饮食记录工具，帮助用户：

1. 快速记录每天吃了什么以及摄入多少卡路里。
2. 查看每日热量和宏量营养汇总。
3. 根据个人资料生成饮食目标。
4. 使用日本常见食品作为起点，也能保存自己的食品。
5. 在没有服务器和 iCloud 的情况下，通过 Files 备份和迁移数据。

## 2. 平台与限制

- 当前实现路线选择 Web/PWA；原生 SwiftUI 方案保留为后续替代路线。Web 方案的具体范围与平台取舍见 `docs/prd-web.md` 和 ADR 0002。
- 首版支持 iPhone/iPad；macOS 通过 SwiftUI/Mac Catalyst 尽量复用。
- 开发阶段可在 iOS Simulator 和 Mac Catalyst 上运行，无需付费开发者证书。
- 直接从 Xcode 安装到 iPhone/iPad 需要开启 Developer Mode；免费个人签名通常约 7 天后需要重新签名。通过 TestFlight 或 App Store 安装则不需要 Developer Mode，但需要相应的 Apple 签名与分发流程。
- 支持中文、英文界面；食品名称支持允许中文、日文、英文任意数量。
- 本地存储，不需要账号、服务器或网络连接。
- 接受免费 Apple Developer 账号的签名限制，安装包可能约每 7 天需要重新签名。
- 不承诺医疗建议；目标和统计仅供个人参考。

## 3. MVP 范围

### 3.1 今日饮食记录

- 按日期和时间查看饮食，记录时间默认当前时间。
- 从食品库搜索食品并选择份量/单位。
- 修改、删除记录。
- 可直接记录一次性热量，不必先创建食品。
- 支持用户直接输入并保存自定义食品。
- 显示每日热量、蛋白质、脂肪和碳水总量，以及与目标的差异。

### 3.2 食品库

- 内置精选日本常见食品。
- 包含代表性的便利店、连锁店、麦当劳食品。
- 每项食品包含名称、份量、热量及宏量营养；品牌字段不纳入 Web 方案。
- 数据集带版本、来源
- 不声称覆盖完整品牌菜单；数据不足时允许用户创建食品。

### 3.3 目标

- 用户可填写年龄、性别、身高、体重和活动量。
- 根据资料、目标体重和目标日期估算每日热量与宏量营养目标。
- 用户可以手动覆盖自动目标。

### 3.4 Files 备份与恢复

- 从系统 Files 导出完整数据为版本化 JSON。
- 从 Files 导入备份。
- 默认合并数据；相同 ID 的记录以导入数据覆盖。
- 导入前显示备份版本和数据概要。
- 对格式错误、版本不支持和损坏文件显示明确错误。
- 不使用 iCloud 自动同步。

### 3.5 通知与 HealthKit

- 用户可设置用餐记录提醒。
- 使用本地通知，不依赖服务器。
- HealthKit 权限为可选：
- 读写体重；
- 写入每日卡路里和营养数据。
- 读运动热量数据；
- 用户拒绝权限或平台不支持时，饮食记录核心流程仍可用。

## 4. 关键用户流程

### 首次使用

1. 选择语言。
2. 可选填写个人资料。
3. 查看或确认每日目标。
4. 进入今日页面。

### 记录一餐

1. 搜索内置食品或用户食品。
2. 选择份量和记录时间。
3. 保存。
4. 立即看到当天汇总变化。

### 创建自定义食品

1. 输入食品名称、默认份量、热量和宏量营养。
2. 输入名称、份量和营养值。
3. 保存到用户食品库。
4. 后续可像内置食品一样记录。

### 备份恢复

1. 从设置中选择导出或导入。
2. 使用系统 Files 选择位置或文件。
3. 展示数据概要和合并结果。
4. 成功或失败都给出明确反馈。

## 5. 非功能要求

- 离线状态下可完成所有核心记录、查询和统计。
- 不上传食品记录、体重或健康数据。
- 导入数据必须经过结构校验，不能因坏文件覆盖现有数据。
- 核心计算结果必须可重复测试。
- 支持浅色/深色模式和动态字体。
- 关键操作支持 VoiceOver 基础可用性。

## 6. MVP 验收标准

- 用户可以在无网络状态下创建、编辑、删除饮食记录。
- 记录份量后，日汇总能正确计算热量和宏量营养。
- 用户可以搜索至少一组内置日本食品，并创建自定义食品。
- 自动目标可由个人资料生成，手动目标可覆盖自动目标。
- 导出的 JSON 能在另一台安装相同版本 App 的设备上恢复。
- 损坏或不支持的备份不会改变已有数据。
- 本地提醒可创建、取消和修改。
- HealthKit 不可用或被拒绝时，App 仍能正常记录饮食。
- 在目标 iPhone/iPad 与 Mac Catalyst 环境完成构建验证。

## 7. 明确不做

- AI 拍照或语音识别食品。
- 条码扫描。
- 云端账号、服务器和 iCloud 同步。
- 社交、分享和多人协作。
- 完整、实时更新的品牌菜单数据库。
- 过敏原和复杂饮食限制筛选。
- 自动生成复杂食谱或医疗/营养治疗建议。

## 8. 后续版本候选

- AI 食品识别与人工确认。
- 条码扫描和食品数据更新。
- 更细的过敏原、饮食偏好和食谱功能。
- 更完善的 HealthKit 双向同步。
- 在确认需求和成本后评估云同步。
