# Diet

A fully **local** web application for meal logging and dieting, built for Japan-based living.
Bundled with a Japanese food library: convenience stores, chains, McDonald's, etc.

Open https://bordercollie-ai.github.io/diet/ to try it out.

Add to Home Screen on your phone to use it as an app.

## Features

- Meal logging with daily calorie/protein/fat/carb summary
- Japanese food library + custom foods
- Auto or manual calorie goals
- JSON export/import backup
- Achievements
- Offline PWA, no accounts or cloud sync
- Touch screen optimizations and accessibility
